Название проекта: Спидозные козявки

Даны два двумерных массива вещественных элементов. Размер исходных массивов не превосходит 10х10 элементов.
Для каждого из массивов указать количество столбцов, содержащих только не положительные элементы.
Если таких столбцов нет ни для одного из массивов, то вывести соответствующее сообщение.
Проверку столбца на наличие указанных элементов оформить в виде процедуры с передачей в нее всех элементов текущего столбца.
